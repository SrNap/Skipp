# 🤖 Skipp

O **Skipp** foi um bot para Discord desenvolvido com foco em diversão e economia para servidores!

Com ele, os usuários podiam acumular moedas, explorar minijogos e aproveitar diversos comandos úteis para tornar a experiência nos servidores mais divertida.

## 📢 Status do projeto

<badge color="danger">Projeto encerrado</badge>

Infelizmente, o desenvolvimento e a operação do Skipp foram encerrados devido à falta de orçamento para manter os custos de hospedagem.

Agradecemos a todos que utilizaram o Skipp, acompanharam seu desenvolvimento e fizeram parte dessa jornada!
